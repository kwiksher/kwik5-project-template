# Kwik book builder

This project template is a Solar2D + Kwik 5 project. A **book** lives under
`Solar2D/App/<book>/` and is selected at runtime by `env.book` in
`Solar2D/main.lua`. Several books can coexist and share `config.lua`,
`build.settings` and the Simulator.

Read `docs/BOOK-VARIANTS.md` for the four variants and the shared contracts, then
the variant doc you need:

| task | doc |
|---|---|
| stills/PSD story book | `docs/STILL-BOOK.md` |
| one video per page | `docs/VIDEO-BOOK.md` |
| per-character layered + cropped video | `docs/CROPPED-VIDEO-BOOK.md` |
| plugin bench / test pages | `docs/DESIGN-BOOK.md` |

The pipeline is in this repo already (`Scripts/`, plus
`Solar2D/custom/components/ogv.lua`); `docs/PIPELINE.md` lists every script and
the one file a book supplies, `Scripts/book.yaml`. Start a variant by copying
`Scripts/book.yaml`, filling in the cast and placements, and running the gates.

For a working reference, read `biscuit-comes-home`
(https://github.com/Kwik-Dev/biscuit-comes-home): a real book built with these
scripts, all four variants side by side, and its `docs/VIDEO-HANDOFF.md` is the
long-form account of every trap the pipeline hits. Treat it as the shape to
copy — its cast, placements and art direction belong in your `book.yaml`.

## Contracts — never guess these

| contract | value |
|---|---|
| page frame | **1920 × 1280** (3:2); content scale **0.25** → 480 × 320 |
| video frame inside a page | **1280 × 720** (16:9), centred |
| chroma colour | **`#00B140`**, probe gate purity ≥ 0.90, ≥10 px margin |
| clip format | Ogg Theora, `yuv420p`, video-only, fps well under `config.lua` fps |
| generated files | start with `-- generated by … do not edit by hand`; fix the source |

Two scale traps that cause "blank / quarter-size" pages: layers sized from
`display.contentWidth` (960 in production, 480 in the editor), and
`components.kwik.layer_image` resolving through `UI.props.imgDir` (editor only).

## Workflow

1. **Decide the variant** with the table in `docs/BOOK-VARIANTS.md`. Cost anchor:
   one page clip ≈ **110 s** on an M5 Pro MPS box (14B i2v, 512×288, 25 frames,
   4 steps); a 3-cast cropped page ≈ 3× that.
2. **Sources first.** Story in `Scripts/book.fountain`, moving-frame direction in
   `Scripts/book.video.yaml`, page geometry in `pages/<page>/page.layers.yaml`.
   Everything under `Solar2D/App/` is generated.
3. **Build.**
   ```bash
   Scripts/build_book.sh                 # stills/PSD chain
   .venv/bin/python Scripts/video_stories.py --app    # video book(s)
   ```
4. **Render video** (GPU host needed):
   ```bash
   .venv/bin/python Scripts/render_local.py --list
   .venv/bin/python Scripts/render_local.py --page <slug>
   .venv/bin/python Scripts/render_local.py --shot <shot-id> --promote --autocrop
   ```
5. **Verify before claiming done** — see gates below.
6. **Look at it.** Run the Simulator and confirm with a capture. Captures are the
   only evidence that survives.

## Traps that cost hours (do not re-derive)

* `plugin.movie` wants a **resource-relative** path; the absolute path from
  `system.pathForFile` gives *attempt to index a nil value*.
* `movie.newMovieRect` can return a wrapper with a nil `.texture` inside a Kwik
  layer. Build the `MovieTexture` and the `ImageRect` yourself and parent them.
* Keep the fixed local `plugin_movie.dylib` (822,432 bytes) in
  `~/Library/Application Support/Corona/Simulator/Plugins/` and **do not declare**
  `["plugin.movie"]` in `build.settings`; declaring installs the 2022 marketplace
  build (901,136 bytes) over it, which frees the decoder on `stop()` and crashes
  on rewind.
* The ogv class takes its **geometry from the poster object**, not from
  `p.x`/`p.y` — centre-positioned posters stack every layer in the middle.
* Force nothing to 16:9: a cropped texture needs `aspect = w/h`, or it stretches.
* The transport **plate is the only tap target**: it must contain the whole
  button row, or buttons are visible and dead.
* Narration must stop in `didHide`, not only in `destroy()` — Kwik keeps the
  previous scene on a page turn, so `destroy()` never runs and the old page talks
  over the new one.
* One narration and one transport per page on a stacked page — first layer only.
* `video_stories.py --app` refuses to run when `clip.ogv` is older than
  `clip.mp4`. Do not skip the encode; a stale clip looks exactly like a render bug.
* Crop for **memory/fill**, never for file size: on three layers it cut texture
  1.69 MB → 195 KB and upload 27 → 3 MB/s, while file bytes rose 10 %.

## Gates

```bash
Scripts/build_book.sh --check                  # stills: sources and generated agree
.venv/bin/python Scripts/video_stories.py --check   # video: derived tree matches sources
.venv/bin/python Scripts/render_local.py --list     # N/N renders done
.venv/bin/python Scripts/chroma_key.py probe out/<slug>/clip.ogv --color '#00B140'
Scripts/page_sweep.sh                          # per-page capture + error count
```

A page is done when: it renders in production mode, the capture shows what it is
supposed to show, the simulator log has 0 Lua errors, and the gates above pass.
"Generated successfully" is not evidence; a capture is.

## Running a book

```lua
-- Solar2D/main.lua
env.book = "<book>-video"          -- or <book> / <book>-video-cropped / <book>_design
env.page = "<page>"
env.mode = "production"             -- development paints the editor guide into captures
```

```bash
"$HOME/workspace/kwik/kwik-visual-code-CLI/kwik5-CLI/kwik" run .   # log: .kwik/logs/simulator.log
```

Known noise in that log: `Cannot create path for resource file 'assets/…'` (the
resolver probes the bare path before `App/<book>/…`), and
`plugin.movie is not configured in build.settings` (expected; see above). Real
problems are `ERROR` lines and Lua tracebacks.
