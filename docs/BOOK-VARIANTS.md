# The four Kwik book variants

A Kwik project is a Solar2D project with one or more **books** under
`Solar2D/App/<book>/`. A book is a folder with `index.lua` (scene order), one
`<page>.lua` scene model per page, and `components/<page>/layers/*.lua`. Books
are selected at runtime by `env.book` in `Solar2D/main.lua`; several books can
live in one project and share `config.lua`, `build.settings` and the Simulator.

This repo is the template: it ships the scripts, the component and the
conventions. The four variants below are the same pipeline with different
emitters — a book picks one by name under `Solar2D/App/<book>/`:

| variant | book name | what a page is |
|---|---|---|
| **Still book** | `<book>` | PSD-derived layers, stills only — the story book |
| **Video book** | `<book>-video` | one flat-field video per page, keyed at runtime |
| **Cropped video book** | `<book>-video-cropped` | a *stack* of per-character videos, each cropped to its character |
| **Design book** | `<book>_design` | a bench: one plugin mechanism per page, with evidence |

Alongside them, [`SPRITE-BOOK.md`](SPRITE-BOOK.md) builds a `<book>_sprites`
catalogue — one page per character showing every pose still, which is where art
defects are actually visible.

All four run in one project: the reference build is `biscuit-comes-home`
(https://github.com/Kwik-Dev/biscuit-comes-home), which ships them side by side
and is the example to read when a contract here is too terse.

Pick with this table, not by taste:

| you need | choose | because |
|---|---|---|
| a readable picture book, offline, no GPU | **still** | art is baked; the runtime draws images |
| movement baked by a video model, one clip per page | **video** | one decoder per page, one transport bar, simplest composition |
| characters that move independently (per-character timing, parallax, layering) | **cropped video** | each character is its own clip; costs N decoders per page |
| to prove a plugin mechanism works before a real book depends on it | **design** | one page per mechanism, evidence attached |

Costs, measured on an Apple M5 Pro (see `VIDEO-BOOK.md` §4 for the profile):
a per-page video clip is **~110 s** of GPU; a per-character clip is the same, so
a 3-cast page costs ~5.5 min as a cropped page and ~2 min as a plain video page.

## What every variant shares

These are the contracts. Get them wrong once and every page inherits it.

| contract | value | why |
|---|---|---|
| page frame | **1920 × 1280** (3:2) | every layer coordinate, every PSD, every thumbnail |
| content scale | **0.25** → 480 × 320 content units | Kwik clamps `kwikGlobal.scale`; do not size from `display.contentWidth` |
| video frame inside a page | **1280 × 720** (16:9) centred | authored frame, not content units — the ogv class scales it |
| chroma key colour | **`#00B140`** | far from every warm palette colour; white smears into cream |
| clip container | **Ogg Theora, yuv420p, video-only** | `plugin.movie` decodes nothing else |
| clip fps | well under `config.lua`'s `fps` | playback advances one frame per `enterFrame` |

Layer files are generated, never hand-edited: each begins
`-- generated by Scripts/… -- do not edit by hand`, and every pipeline has a
`--check` gate that fails when the tree drifts from its sources. If you find
yourself editing a generated file, fix the source.

## The page model, in one example

```lua
-- Solar2D/App/<book>/<page>.lua  (generated)
local model = {
  components = {
    layers = {
      { ["<page>_bg"] = { } },                                  -- backdrop image
      { ["<page>_video"] = { class = { "ogv" } } },              -- video layer(s)
    },
    audios = { }, groups = { }, timers = { }, variables = { }, joints = { }, page = { },
  },
  commands = { },
  onInit = function(scene) end,
}
return require('controller.scene').new(sceneName, model)
```

A layer entry is `{ [layerName] = { class = { "<class>" } } }`. The runtime loads
`components/<page>/layers/<layerName>_<class>.lua` if it exists, else
`components/<page>/layers/<layerName>.lua`. That naming rule is what lets one
page hold **several** video layers: `<slug>_video_ogv.lua` per layer.

Hyphenated keys **must** be quoted (`["<page>"]`), or Lua parses the key as a
subtraction, `require()` fails, and Kwik silently falls back to its legacy
`components.<page>.index` path.
